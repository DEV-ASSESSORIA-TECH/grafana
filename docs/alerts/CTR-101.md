## O que significa

Um container que existia nas últimas 24 horas não está mais rodando. Container removido de propósito some deste alerta depois de 24 horas.

## Verificar

- docker ps -a e docker logs <container>.
- Se o compose foi alterado ou o container removido de propósito.

## Resolver

- Subir de novo: docker compose up -d no projeto do container.
- Removido de propósito: silenciar até o alerta sumir.
