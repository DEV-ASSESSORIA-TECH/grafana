## O que significa

O healthcheck do container está falhando. O processo roda, mas a aplicação não responde como deveria.

## Verificar

- docker inspect <container> (seção State.Health) e docker logs <container>.

## Resolver

- Corrigir a causa (dependência fora, configuração) e reiniciar o container.
