# LIN-101 · Servidor Linux crítico sem métricas

## O que significa

Um servidor Linux classificado como crítico parou de enviar métricas. Pode estar desligado, travado ou com o Alloy parado.

## Verificar

- Servidor responde a ping e SSH?
- systemctl status alloy.
- Alertas da VM (HYP-111/114) ou do host também disparando?

## Resolver

- Servidor fora: ligar ou reiniciar pela console do Hyper-V.
- Servidor de pé: systemctl restart alloy.
