## O que significa

O tiflux-exporter responde, mas não consegue ler a API do TiFlux. As métricas da fila ficam congeladas no último ciclo bem-sucedido.

## Verificar

- `docker logs --tail 50 tiflux-exporter`: HTTP 401 (token), 403 (perfil sem permissão), 429 (limite) ou erro de rede.
- `tiflux_api_requests_total` por `code` no Prometheus.
- Status da API do TiFlux.

## Resolver

- Token inválido ou expirado: gerar outro no TiFlux, atualizar o `.env` do exporter e reiniciar o container.
- Limite de requisições: reduzir `TIFLUX_REQUEST_BUDGET` se outra integração usa o mesmo token.
