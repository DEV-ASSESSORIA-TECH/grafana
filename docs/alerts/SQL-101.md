## O que significa

O coletor não consegue abrir conexão com o banco SQL Anywhere. Os sistemas que usam o banco provavelmente estão parados.

## Verificar

- Serviço do SQL Anywhere no servidor (services.msc ou `Get-Service *SQL*Anywhere*`).
- Log do coletor: `C:\ProgramData\GrafanaLabs\Alloy\logs\sqlanywhere-collector-AAAAMMDD.log` (mensagem do driver ODBC).
- Se o serviço está rodando: o banco foi iniciado? O usuário de monitoramento existe e a senha não mudou?

## Resolver

- Iniciar o serviço ou o banco.
- Senha ou usuário trocados: reconfigurar em `install.ps1 -ReconfigureSqlAnywhere` (menu Módulos opcionais → Reconfigurar SQL Anywhere).
