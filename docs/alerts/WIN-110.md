## O que significa

Um serviço essencial do Active Directory parou num controlador de domínio. Autenticação, DNS, replicação ou horário do domínio podem falhar.

## Verificar

- Estado do serviço (Get-Service NTDS, DNS, Netlogon, Kdc, DFSR, ADWS, W32Time).
- Event Log Directory Service, DNS Server e DFS Replication.
- dcdiag /q no controlador de domínio.

## Resolver

- Iniciar o serviço e conferir o Event Log.
- Se não iniciar, ver dependências e o erro antes de reiniciar o servidor.
