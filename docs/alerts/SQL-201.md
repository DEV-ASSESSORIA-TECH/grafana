## O que significa

O cache do SQL Anywhere não encontrou página livre para alocar (CachePanics). O cache está pequeno demais para a carga atual.

## Verificar

- Painel Mapa do cache e Composição do cache: cache livre perto de zero?
- Se o tamanho do cache (-c / -ch) foi reduzido recentemente.
- Pressão de memória: esperas e negações de memória de consulta no mesmo horário.

## Resolver

- Voltar o cache ao tamanho anterior ou aumentar o máximo (-ch) e reiniciar o servidor de banco em janela combinada.
