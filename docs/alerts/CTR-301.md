## O que significa

O servidor continua enviando métricas, mas as dos containers pararam. Os alertas CTR deste servidor não funcionam enquanto isso.

## Verificar

- Módulo Docker do Alloy ativo (alloy.sh, status).
- Acesso do Alloy ao socket do Docker.

## Resolver

- Reativar o módulo Docker no alloy.sh e reiniciar o Alloy.
