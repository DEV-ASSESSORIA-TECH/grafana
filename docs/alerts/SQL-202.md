## O que significa

Requisições esperaram memória de consulta e não conseguiram. Consultas ficam lentas ou falham.

## Verificar

- Cache livre e alocado para outros fins no painel Composição do cache.
- Consultas pesadas rodando em paralelo no horário (relatórios, fechamentos).
- Se o cache foi reduzido recentemente.

## Resolver

- Aumentar o cache se estiver sem folga.
- Reagendar processos pesados para fora do horário de uso.
