## O que significa

A última tentativa publicou um backup utilizável, porém incompleto (fallback). Ele não conta como sucesso. No BackupSeven: o dump normal do banco falhou e foram publicados os archives `_DEGRADED` e `_GRANULAR_DEGRADED` (exit code 5).

## Verificar

- `manifest.json` do archive `_GRANULAR_DEGRADED`: status de cada tabela e view.
- Arquivos `_FAILED.txt` no mesmo archive: objeto, erro (ex. tabela marcada como corrompida) e horário.
- Log da execução, etapa `Database/Degraded`.

## Resolver

- Reparar os objetos que falharam no MySQL (ex. `REPAIR TABLE`) em janela combinada e executar um backup manual.
- Enquanto não for corrigido, guardar o último backup normal: ele é o ponto de recuperação completo.
