## O que significa

Um filesystem do servidor Linux passou de 85% de uso.

## Verificar

- df -h e du -xh --max-depth=1 no ponto de montagem.
- docker system df, se houver containers.

## Resolver

- Limpar logs, imagens e volumes Docker antigos (docker system prune) ou aumentar o disco.
