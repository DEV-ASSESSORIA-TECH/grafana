## O que significa

O Uptime Kuma deixou de receber o heartbeat do host Hyper-V. O host está fora, sem rede até o monitoramento, ou a tarefa do heartbeat parou.

## Verificar

- Host responde a ping e RDP?
- HYP-101 também está disparando?
- Tarefa agendada do heartbeat e saída HTTPS do host até o Kuma.

## Resolver

- Host fora: ligar e conferir as VMs.
- Host de pé: reconfigurar o heartbeat (alloy.ps1, opção de heartbeat).
