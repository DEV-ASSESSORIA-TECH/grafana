## O que significa

Um filesystem do servidor Linux está somente leitura. O kernel faz isso depois de erro de disco ou de filesystem.

## Verificar

- dmesg | grep -iE 'ext4|xfs|I/O error'.
- Disco virtual e volume do host (HYP-110, HYP-202).

## Resolver

- Corrigir a causa, rodar fsck no próximo boot e reiniciar a VM.
