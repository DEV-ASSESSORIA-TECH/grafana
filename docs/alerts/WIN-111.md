## O que significa

Um serviço de aplicação (banco de dados ou sistema Domínio) parou. Os usuários podem estar sem acesso ao sistema.

## Verificar

- Estado do serviço no servidor.
- Event Log Application no momento da parada.
- Espaço em disco (WIN-201/202).

## Resolver

- Iniciar o serviço e confirmar o acesso de um usuário.
