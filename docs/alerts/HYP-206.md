## O que significa

A CPU do host Hyper-V está acima de 90% há mais de 30 minutos. Todas as VMs do host ficam lentas.

## Verificar

- Painel CPU por VM: qual VM está consumindo.
- Disputa por CPU (painel Disputa por VM).

## Resolver

- Tratar a VM que está consumindo (processo travado, carga anormal) ou reduzir as vCPUs dela.
