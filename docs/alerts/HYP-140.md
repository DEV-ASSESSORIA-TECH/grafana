## O que significa

Um serviço do Hyper-V (vmms ou vmcompute) parou no host. Sem ele não é possível gerenciar nem ligar VMs.

## Verificar

- Estado do serviço no host (Get-Service vmms, vmcompute).
- Event Log Hyper-V-VMMS-Admin.

## Resolver

- Iniciar o serviço. Se falhar, ver o erro no Event Log antes de reiniciar o host.
